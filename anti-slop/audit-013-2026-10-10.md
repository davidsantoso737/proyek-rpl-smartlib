# Audit 013 — Eksemplar, cetak massal, back link, focus (2026-10-10)

Scope: `manage_copies.html`, `copy_label_batch.html`,
`manage_copy_form.html`, `_back_link.html` (satu-satunya perubahan
global, presentasi saja), aturan `.manage-form` di `input.css`.
`copy_label_print.html` dan seluruh backend tidak disentuh.

Inspected: ketiga template (kolom, form GET/POST, action, CSRF,
confirm, empty copy, print classes), `BookCopyForm` (field aktual),
`copy_label_batch/print` views (context books/selected_book/copies,
`?book=`/`?copy=` berulang), `_back_link` (dipakai ~20 halaman),
aturan fokus global, tidak ada ikon QR terverifikasi di set proyek,
tidak ada badge semantik untuk status eksemplar (mentah di semua
halaman), tidak ada kontrol pilih-semua di batch.

Rencana: copies jadi satu container (h1 compact + meta + aksi,
tabel token dasbor, status badge netral, QR teks ringkas + Ubah ikon
pensil, form POST/CSRF/confirm utuh); batch jadi kartu sistem
(select flex-1 + tombol, daftar checkbox max-h scroll, tombol cetak
biru primer, copy/empty string utuh); copy form jadi kartu
`max-w-3xl` + `manage-form` (grid 2 kol proporsional, loop field
utuh, Simpan + Batal); `_back_link` jadi tombol sekunder (tujuan dan
label sama di semua halaman); aturan `.manage-form` dikecualikan
untuk checkbox/radio agar kontrol tanpa ring tetap punya outline,
plus dokumentasi hasil audit global (penghapusan outline global
ditolak: kontrol tulisan tangan tersebar di 15+ template dan
   ketergantungan hanya bisa dipastikan per halaman).
