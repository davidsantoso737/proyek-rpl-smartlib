# Audit 023 - 2026-11-12

Pemicu: laporan bahwa menu verifikasi Telegram tidak tampil saat login sebagai pustakawan.

Cakupan: sidebar, dashboard pustakawan, halaman verifikasi Telegram, dan partial navigasi terkait.

## Temuan

### F1 - HIGH - Menu Verifikasi Telegram tidak ada di partial yang dipakai

`templates/base.html:23` dan `templates/base.html:63` merender `partials/_app_sidebar.html`, tetapi item Verifikasi Telegram hanya ditambahkan ke `partials/_librarian_sidebar.html:68`. File itu tidak dirender oleh template mana pun. Akibatnya halaman `/integrasi/telegram/verifikasi/` tidak punya entry navigasi.

Rujukan: R-24, C-2.

### F2 - MEDIUM - Dua item navigasi aktif bersamaan di halaman verifikasi Telegram

`_librarian_sidebar.html:58` dan `_app_sidebar.html:52` menganggap semua URL yang mengandung `verif` sebagai halaman Verifikasi materi. Halaman `telegram:verification_list` juga mengandung kata `verification`, sehingga Verifikasi materi dan Verifikasi Telegram akan sama-sama ditandai aktif setelah menu Telegram ditambahkan.

Rujukan: R-31, C-4.

### F3 - HIGH - Ringkasan dashboard menghitung antrean Telegram tetapi tidak menyebutnya

`pending_total` di `apps/core/context_processors.py:40` sudah menjumlahkan `pending_telegram`, tetapi teks di `templates/accounts/dashboard.html:153` hanya merinci pinjam, e-book, materi, dan hapus. Jika hanya antrean Telegram yang terisi, pengguna melihat "1 hal menunggu aksi" dengan semua rincian bernilai 0.

Rujukan: R-38, C-2.

### F4 - HIGH - Tabel antrean operasional tidak punya baris Verifikasi Telegram

Tabel di `templates/accounts/dashboard.html:168-221` tidak punya baris atau tautan ke `telegram:verification_list`, padahal `pending_total` di header tabel sudah mencakup antrean Telegram.

Rujukan: R-24, C-2.

### F5 - LOW - Partial sidebar pustakawan duplikat dan tidak terpakai

`templates/partials/_librarian_sidebar.html` sudah tidak direferensikan dan isinya mulai berbeda dari `_app_sidebar.html`. Ini membuat perubahan navigasi mudah masuk ke file yang salah, seperti yang terjadi pada temuan F1.

Rujukan: C-1, R-31.

### F6 - MEDIUM - Tidak ada regression test untuk navigasi dan antrean Telegram

Test yang ada memverifikasi isi halaman verifikasi dan otorisasi, tetapi tidak memverifikasi bahwa menu muncul untuk pustakawan, bahwa status aktif tidak bentrok, dan bahwa dashboard merinci antrean Telegram.

Rujukan: R-35, C-4.

## Dampak

Pustakawan tidak menemukan jalur ke halaman persetujuan Telegram dari navigasi normal. Dashboard juga menampilkan angka yang tidak dapat dicocokkan dengan rincian antrean.

## Rekomendasi urutan perbaikan

1. F1: tambahkan item menu ke `_app_sidebar.html`.
2. F2: persempit kondisi aktif Verifikasi materi ke namespace dan nama URL materi.
3. F3 dan F4: selaraskan ringkasan dan tabel dashboard dengan `pending_telegram`.
4. F5: hapus partial duplikat yang tidak terpakai.
5. F6: tambahkan test regresi untuk menu, status aktif, dan dashboard.

## Status

Belum ada perubahan source. Menunggu persetujuan nomor temuan.
