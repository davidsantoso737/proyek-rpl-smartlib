# Audit 017 — Global focus-state unification (2026-10-10)

Metode: script pemindai seluruh template (`focus_audit.py`, di luar repo)
memeriksa setiap tag input/select/textarea multiline: 0 kontrol teks
tanpa `focus:ring` (widget Django menerima INPUT_CLASS ber-ring;
file input dan search modal/AI ikut ter-cover). Inventaris utility:
`focus:ring-2` x29, tanpa `ring-4`/`ring-[3px]`/`ring-1` di mana pun,
`focus-visible:ring` x3. Tidak ada single ring oversized.

## Temuan: penyebab tunggal, bukan banyak masalah tersebar

1. GLOBAL: tidak ada ring tebal di mana pun. Efek "tebal/berlapis"
   berasal dari penumpukan dua indikator pada keyboard focus:
   `focus:ring-2` (box-shadow biru, tanpa layout shift) + outline
   global 2px `#1d4ed8` offset 2px (CSS unlayered menang atas
   `focus:outline-none` ber-layer). Fokus mouse hanya menampilkan
   ring, sehingga keluhan muncul "saat diklik/dipilih/fokus keyboard".
2. LOKAL: tidak ada komponen dengan style fokus menyimpang; semua
   memakai pola yang sama.

## Keputusan: perbaiki di sumber bersama, aman dan minimal

Karena cakupan ring terbukti 100% pada kontrol teks, aturan
`.manage-form` yang terfragmentasi diganti satu aturan global:
kontrol teks (minus checkbox/radio/submit/button/hidden/image)
memakai ring-2 sebagai indikator tunggal; tombol, tautan, checkbox,
dan radio tetap memakai outline global. Pengecualian `#qr-reader`
menjaga kontrol injeksi library pihak ketiga. Tidak ada template,
Python, atau utility yang diubah; tidak ada `!important`.
