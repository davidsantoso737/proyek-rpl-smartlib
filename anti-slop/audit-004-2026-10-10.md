# Audit 004 — Connected sidebar/header seam (2026-10-10)

Scope: horizontal gap between librarian sidebar and workspace header.
Inspected `base.html` shell (lines 20-27). No page wrappers involved.

## Gap source (verified)

Single cause: `lg:gap-6` on the shell grid puts a 24px page-background
gutter between the sidebar card and the header bar, so they read as two
disconnected cards. No workspace padding, header margin, or
route-specific override contributes.

## Approved fix (per task directive)

- Drop `lg:gap-6` so the regions touch (mobile single-column flow
  untouched: gap utility is `lg:`-scoped).
- Header gains `lg:border-l-0` so the sidebar's own right border is the
  single seam line (no double border), plus `lg:rounded-bl-none` so the
  header's bottom edge meets that seam in a clean T-junction instead of
  curving away from it.
- Sidebar untouched (width, brand, groups, icons, active state, scroll,
  account block); its `border-slate-200/80` plus existing `shadow-sm`
  on both surfaces is the subtle boundary. No new colors, shadows, or
  effects.
- Title, KPI, table, and content spacing untouched.

## Follow-up (2026-10-10): fixed, `base.html` only

- Dropped `lg:gap-6` from the shell grid; header adds `lg:border-l-0`
  and `lg:rounded-bl-none`. Sidebar classes, brand, groups, icons,
  header controls, title/content spacing all unchanged.
- Mobile flow untouched (gap and seam utilities are `lg:`-scoped).
